## ✨ ABOUT THE PROJECT

Ever wanted to turn a website link, text, or any piece of information into a QR code within seconds?

**QR Code Generator** is a simple and beginner-friendly Python project that makes it possible.

Built using Python's `qrcode` library and Pillow, this application allows users to generate customized QR codes and save them as PNG images.

Whether it's a website, LinkedIn profile, or plain text, simply provide the input and generate your QR code.

> **One Input. One Scan. Endless Possibilities.**

## ⚙️ GETTING STARTED

Want to generate your own QR codes? Follow these steps.

### Prerequisites

- Python 3.x
- pip package manager

### 1. Clone the Repository

```bash
git clone https://github.com/abhishek-s-gupta/QR-Code-Generator.git
```

### 2. Navigate to the Project

```bash
cd QR-Code-Generator
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
python main.py
```

That's it! Your QR Code Generator is ready.
